# Dated resolution of conflicting timing specifications (2026-10-20, revised after two independent reviews)

## The two conflicting specifications
- **The protocol and its evaluator (max):** the original public protocol deposit (Zenodo 10.5281/zenodo.23462442, created 2026-10-19 01:36:22 UTC) and its archived evaluator `scripts/prereg_test.py` (SHA-256 `630815cc1400f0434dc9f30c8ce08cc42635ee5d1d429338c4010f6115043366`; unchanged in protocol v1.2 = 23474138 and v1.3 = 23477866) specify a "recovered" timing tolerance of **max(3 sigma_pred, 30 min)**. In the executable:
  - `sigma_pred` is the arithmetic mean of the frozen `sigma_min` values of the coverage-qualified predictions;
  - the tested offset is the mean fitted offset, weighted by inverse depth variance.
- **The object files (min):** 37 v2 registrations generated by `scripts/prereg_v2.py` instead say "within +-3 sigma_min (and in any case within +-30 min)". That can reasonably be read as **min(3 sigma, 30 min)**, applied to individual events.

## Chronology
- **We do not claim that the protocol preceded all object files.** The v2 registrations of TIC 80387959 and TIC 120444365 were publicly archived before the protocol: GitHub commit 24cd0de at 2026-10-18 23:24 UTC, and Zenodo 23460915.
- **Round-2 and later v2 files** postdate the protocol deposit.

## Resolution
This amendment resolves the conflicting timing clauses in the 37 identified TESS-v2 registrations. It adopts the already-public max() implementation as a dated precedence decision. It does not assert that the protocol preceded every object file, or that the original min() reading was impossible.

The decision is made before the test photometry of any applicable, non-withdrawn test has been evaluated. The withdrawn TIC 88407114 S106 test is excluded; its freeze had fitted S106 data. Some test sectors were already public at freeze; see ERRATUM_S106_DATA_AVAILABILITY_2026-10-20.md.

For each applicable, non-withdrawn TESS-v2 test we will also report the individual-event assessment under min(3 sigma, 30 min). This is a dated adoption of precedence; it does not erase the earlier wording.

## Impact
The two gates differ whenever sigma is not exactly 10 min: max() is wider both for smaller and for larger sigma. Among the Sector 106 objects:

The full per-object, per-epoch table is in `results/REVIEW_timing_rule.md` §4; its TIC 88407114 S106 rows are now historical only, because that test is withdrawn. Timing tolerance alone does not decide an outcome.

## Scope
This resolution covers only the listed v2 TESS timing clauses. It does not replace:
- the older v1 rules (60-min clause, depth 0.6–1.5×);
- TIC 61310956's dedicated v3 ground-based rules;
- TIC 89247735's v1 ground-based test of record.

Three v1 files (TIC 80387959, 120444365 and one withheld object) received the timing addendum in error. Each now carries a dated correction withdrawing it.

## What is preserved
- **Prediction CSVs:** the original bytes and their recorded SHA-256 digests are unchanged.
- **Markdown files:** dated notes are appended after the original text, which is untouched. The amended Markdown files therefore have new file hashes; historical releases and their manifests remain intact.

## Known limitations of the frozen evaluator
The frozen executable works in this order:
1. checks coverage (INSUFFICIENT if fewer than 2 qualifying windows);
2. tests RECOVERED;
3. tests EXCLUDED;
4. only then tests INCONSISTENT;
5. otherwise returns AMBIGUOUS.

It does not measure or check transit duration, it averages timing offsets across transits, and it does not separately require full transit coverage for EXCLUDED.

We will retain and report its literal output, but we will not claim that the output alone verifies every written criterion. For the remaining tests whose photometry has not been inspected, a separately versioned conformance procedure and its precedence will be fixed and published before inspection.

Its exact timing gate is |Σ(w_i Δt_i)/Σw_i| ≤ max[3·mean(σ_pred,i), 30 min], where w_i = 1/(depth_err,i)² and both summaries use the coverage-qualified prediction rows. These are inverse depth-variance weights, not timing-uncertainty weights.

## Template
From 2026-10-20 the generator template states this exact gate and refers duration and full-coverage criteria to the conformance procedure.
