# Acknowledgements and use of AI

This work uses data from the TESS mission, obtained from MAST. The 2-minute-cadence observations of TIC 80387959 were requested
through the TESS Director's Discretionary Time programme (DDT 104). We thank the TESS mission and its DDT programme.

AI was used in developing the DDT proposal and in the data analysis, under the author's direction:

| Use | Vendor | Models |
|---|---|---|
| DDT proposal text; data analysis, code and reports | Anthropic | Claude Opus 5.5 (`claude-opus-5-5`), Claude Fable 5.1 (`claude-fable-5-1`), Claude Fable 5.2 (`claude-fable-5-2`) |
| External review | OpenAI | Codex: `gpt-6-astra`, `gpt-6-luna`, `gpt-6.1-sol` |
| Metadata monitoring | Grok Bot | model and version not available |
